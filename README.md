# SkyCast

SkyCast is a weather application that provides current weather information for any location using the Visual Crossing Weather API. The application fetches weather data asynchronously and presents it through a clean and responsive user interface.

## Features

- Search weather information by location
- Real-time weather data from the Visual Crossing Weather API
- Animated and visually appealing interface
- Modular codebase bundled with Webpack

## Built With

- HTML
- CSS
- JavaScript
- Webpack
- Visual Crossing Weather API
